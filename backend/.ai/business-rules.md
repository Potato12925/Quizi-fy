# BUSINESS RULES

## Documents

- Teacher only uploads assigned subject
- Max size 20MB
- Allowed: PDF, DOCX, TXT

## Questions

- Only approved questions usable
- AI questions start as draft
- Questions used in practice cannot hard delete

## Practice

- Random approved questions only
- Save attempt history
- Auto-save student answers

## Class Management

- No duplicate student in class
- No duplicate teacher assignment

## Restore/Backup

- Admin only
